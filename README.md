# Pulse Width Measurement using STM32F401CCU6

## Overview
This project demonstrates how to measure the width of an incoming pulse using the STM32 Input Capture feature in bare-metal programming.

## Final Outcome
- Measure the duration of an incoming pulse.
- Capture pulse width using TIM2 Input Capture.
